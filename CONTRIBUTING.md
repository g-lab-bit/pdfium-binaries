# Contributions

**This repository does not accept external contributions.** It is a
single-maintainer fork maintained solely for the maintainer's
downstream needs.

If you are interested in PDFium build automation generally, please
contribute upstream at
[bblanchon/pdfium-binaries](https://github.com/bblanchon/pdfium-binaries)
or to [PDFium itself](https://pdfium.googlesource.com/pdfium/).

Pull requests opened against this repository will be closed
automatically. Issues are disabled. Discussions are disabled.

Thank you for understanding.
